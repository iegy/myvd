# MYVD للويندوز (نسخة Portable)

برنامج تحميل فيديو وصوت من يوتيوب وتيك توك وأكثر من 1000 موقع، بنفس فكرة تطبيق MYVD للأندرويد.

## التشغيل
1. حمّل الملف `MYVD-Windows-Portable.zip` من صفحة Releases.
2. فك الضغط في أي مكان (مثلاً سطح المكتب أو فلاشة).
3. شغّل `MYVD.exe`. مفيش تثبيت.

> أول مرة ممكن يظهر تحذير SmartScreen لأن البرنامج غير موقّع: اضغط **More info** ثم **Run anyway**.

## المزايا
- لصق الرابط وتحليله، أو سحب الرابط وإفلاته على النافذة.
- اختيار الجودة (حتى أعلى جودة) أو تحويل لصوت MP3 / M4A.
- قوائم التشغيل مع تحديد الفيديوهات المطلوبة.
- طابور تحميل: إيقاف مؤقت واستئناف وإلغاء وتحميلات متزامنة.
- **معاينة بدون إعلانات** قبل التحميل (عبر مشغّل mpv المرفق).
- تحديث yt-dlp بضغطة زر من الإعدادات.
- تطبيق الأندرويد: القائمة ← نسخة الأندرويد (رابط + QR كود).

## محتويات المجلد
- `MYVD.exe` البرنامج.
- `bin\yt-dlp.exe` و`bin\ffmpeg.exe` و`bin\mpv\mpv.exe` الأدوات المساعدة (لا تحذفها).
- `data\` الإعدادات وقائمة التحميلات (تُنشأ تلقائياً؛ انقل المجلد كله وستنتقل معك).

الملفات تُحفظ افتراضياً في `Downloads\MYVD`، ويمكن تغييره من الإعدادات.

## للمطورين
```
pip install -r requirements.txt
python -m unittest discover -s tests
python src/main.py
```
البناء يتم تلقائياً بـ GitHub Actions (`Build Windows Portable`) وينشر الإصدار تحت الوسم الثابت `latest`.
